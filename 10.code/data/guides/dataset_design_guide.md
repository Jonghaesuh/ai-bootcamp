# 데이터셋 설계 가이드

ML 데이터셋을 설계할 때 확인할 체크리스트입니다. 각 절은 독립된 검색 단위(청크)입니다.

## 분석 단위 선택

- 한 행이 무엇인지(고객, 주문, 상품, 고객×월 등)를 먼저 정한다. 예측 결과로 취할 행동의 대상과 같아야 한다.
- 분석 단위 키는 프로파일로 검증한다. 고유값 수가 행 수와 같은지, 같은 사람이 여러 키를 갖지 않는지 확인한다.
- 키 이름만 보고 단위를 단정하지 않는다. 주문마다 새로 발급되는 고객 키가 있을 수 있다.
- 단위보다 세밀한 테이블(주문 상세, 결제 내역)은 단위 키로 집계한 뒤 조인한다. 그대로 조인하면 행이 늘어난다.

## 기준 시점

- 기준 시점은 예측을 실행하고 행동을 취하는 시각이다. 행동 시점이 늦어지면 비즈니스 효과도 달라지므로 임의로 옮기지 않는다.
- 피처는 기준 시점 이전에 확정된 정보만 쓴다. 타깃은 기준 시점 이후의 일정 기간에서 관측한다.
- 기준 시점이 사건 기반(첫 구매 직후)이면 행마다 다르고, 달력 기반(매월 1일)이면 스냅샷 테이블을 만든다.

## 데이터 누수 점검

- 피처의 원천 컬럼마다 값이 확정되는 시점(available_at)을 확인하고 기준 시점보다 늦으면 제외한다.
- 자주 놓치는 누수: 배송 완료일·배송 소요일, 리뷰 점수·리뷰 내용, 최종 주문 상태, 이후 주문 수, 전체 기간 집계값(평균 구매액 등).
- 전체 기간 집계를 피처로 쓰려면 기준 시점 이전 기간으로 제한한다.
- 성능이 비정상적으로 높으면(AUC 0.95 이상 등) 누수를 먼저 의심한다.

## 관측 기간 절단

- 데이터 마지막 시각에서 타깃 기간만큼 거슬러 올라간 시각 이후의 기준 시점 행은 타깃을 끝까지 관측할 수 없다. 제외하지 않으면 양성이 음성으로 잘못 기록된다.
- 데이터 마지막 구간에 수집이 불완전한 기간이 있으면 그 구간도 마지막 시각 계산에서 제외한다.

## 관측 윈도우와 타깃 윈도우

- 관측 윈도우: 피처를 집계하는 기준 시점 이전 기간 (예: 직전 90일).
- 타깃 윈도우: 타깃을 판정하는 기준 시점 이후 기간 (예: 이후 90일). 요구사항에 기간이 없으면 추측하지 말고 질문한다.
- 타깃 윈도우를 늘리면 양성 비율이 올라가지만 예측과 행동 사이의 거리도 멀어진다.

## 학습·검증·테스트 분할

- 시간에 따라 변하는 문제는 기준 시점 순서대로 나눈다 (out-of-time). 무작위 분할은 미래 정보가 학습에 섞여 성능을 과대평가한다.
- 같은 고객이 여러 행을 가지면 고객 단위로 분할이 겹치지 않게 한다.
- 분할별 행 수와 타깃 비율을 확인하고, 테스트 구간이 너무 짧거나 타깃이 거의 없으면 경계를 조정한다.

## 클래스 불균형 대응

- 양성 비율이 낮으면(2% 미만 등) 정확도 대신 PR-AUC, 상위 N% 정밀도·Lift로 평가한다.
- 양성 수가 너무 적으면(수십 건) 모델링 실익이 낮다. 타깃 정의를 넓히거나 기간을 늘리는 안을 제안한다.
- 리샘플링·가중치는 학습 데이터에만 적용하고 검증·테스트 분포는 건드리지 않는다.

## 결측과 품질

- 결측률이 높은 피처는 결측 자체가 의미가 있는지(예: 리뷰를 남기지 않음) 확인하고, 의미가 있으면 결측 여부 피처를 따로 만든다.
- 기준 시점 이후에만 채워지는 컬럼은 결측 패턴 자체가 누수가 될 수 있다.

## Olist 데이터 주의사항

- customers.customer_id는 주문마다 새로 발급된다. 고객 단위 분석과 재구매는 customer_unique_id로 한다.
- order_status는 데이터 추출 시점의 최종 상태다. 모집단 필터로 쓰면 기준 시점 이후의 취소 정보가 섞일 수 있으니 의도를 명시한다.
- 주문 하나에 결제(order_payments)와 상품(order_items)이 여러 행일 수 있다. 주문 단위로 집계한 뒤 조인한다.
- geolocation은 우편번호 앞자리가 고유하지 않다. 우편번호별 평균 좌표로 집계한 뒤 조인한다.
- 리뷰는 대부분 배송 이후에 생성된다. 구매 시점 기준 예측에서는 리뷰 정보를 피처로 쓸 수 없다.
- 2018-09 이후 주문은 수가 급감해 불완전하다. 관측 기간 절단 계산에서 데이터 마지막 시각을 2018-08-31 전후로 본다.
- 고객 대부분(약 97%)이 주문을 한 번만 해 재구매 타깃은 양성 비율이 매우 낮다.
